# DS-TH09-AI 3.3.0-test

简明功能与逻辑见 [版本说明](版本功能与逻辑说明.md)。

《东方花映塚》日文版 v1.50a 的本地 2P AI 源码。Lua 负责决策，本项目的原生启动器和支持模块提供输入隔离、窗口处理及只读感知，运行时使用上游 ka_ai_duka v1.7。

第三代在开花策略基础上限制可见范围、注意力和避弹变向，并开放玩家配置。难度名称用于选择预算，暂不按固定生存秒数标定。需要自行准备游戏；仓库不包含游戏本体。

## 三个源码版本

| git-project1 | 0.1.9 | 第一代避弹、随机 C、毒与激光感知 |

三者是独立源码快照，配置和发行文件应与各自版本配套。本文说明第三代的现行行为。

## 玩家能力设置

完整发行包内双击 `set-difficulty.cmd`，保存后下次启动生效。对应字段位于 `launcher-settings.json` 的 `ai` 对象中。

| 参数 | 字段 | 默认值 | 可调范围 |
| --- | --- | --- | --- |
| 每秒避弹变向上限 | `move_change_budget` | 6 | 1～10，整数 |
| 圆形视野半径 | `vision_radius` | 448/3 ≈ 149.33 | 16～640 |
| 注意力容量 | `attention_capacity` | 跟随预设 | 1～256 |
| 每秒新目标额度 | `attention_recovery_per_second` | 跟随预设 | 0.1～256 |

以下为没有手动覆盖时的预设；各预设的默认变向上限都是 6，默认视野半径都是 149.33。

| 预设 | 注意力容量 | 每秒新目标额度 |
| --- | --- | --- |
| human45 | 6 | 5 |
| human90 | 9 | 7 |
| human120 | 12 | 9 |
| human150 | 16 | 12 |
| human180 | 20 | 15 |
| human200（默认） | 26 | 19 |
| human240 | 32 | 24 |
| human300 | 40 | 30 |
| human480 | 55 | 40 |
| unlimited | 120 | 90 |
| mech | 默认关闭注意力限制 | 默认关闭注意力限制 |

**没有内置 human600。** unlimited 仍有注意力预算；mech 默认跳过注意力过滤，但圆形视野和变向限制仍生效。兼容设置中的显式 `ai.enabled` 可以覆盖注意力开关。

菜单切换预设会清除两个手动注意力覆盖值，保留当前视野、变向和其他设置。因此，切换预设不会自动把自定义视野或变向恢复成表中默认值。完整套装、拉满效果与恢复命令见 [参数套装文档](docs/PARAMETER-PRESETS.md)。

视野以自机为圆心，使用游戏坐标，不随窗口像素缩放。避弹与放 C 的目标、连爆资源和压力判断共用圈内快照；长激光或长条 EX 的真实形状伸入圆内即可被看见，不能因未来可能飞入而提前可见。自身状态和对手气槽仍可读取。

注意力数值是按速度和形状加权的威胁单位，不是子弹颗数。激光、毒云和敌人沿用免注意力预算处理，但仍受视野限制。每秒变向使用 60 次战斗回调的滚动窗口；持续同向移动不重复计数，平静走位不消耗此预算，最短变向间隔仍有效。

四项拉满为 `10 / 640 / 256 / 256`：视野可覆盖正常单侧全场，目标跟踪与新目标纳入能力增加，允许更频繁变向。角色速度、动作门、能量、蓄力和短期规划仍有限；数值更大不保证每局更强。视野跟随自机，因此本功能不禁止连续横穿场地。

## 行为与边界

在 Match Mode → Human vs Human 中控制 2P；2P 的 `Charge Type` 必须为 `Slow`，AI 不使用 X。保留连爆资源判断、C2 循环及受真实能量与动作门约束的压力反馈，不承诺必放 C、纯开花或固定存活时间。`seconds` 顶层配置是接管时限，默认 600，0 为不限时，与难度预算独立。

C1 的几何覆盖和预计连爆不等于确认击杀或回能；部分自定义攻击仍使用有限模型。原生感知不改变游戏子弹生成、碰撞物理、2P HP 或能量。离线回归不能代替实战验证。

调试 CSV 为 162 列：原始对象数量保留作对照，新增圈内/圈外计数与实际能力配置；`field_erasable` 和链条收益来自圈内快照。分析旧日志时应核对版本和列定义。

## 从源码构建

在仓库根目录运行，示例编译器路径请替换为自己的完整 TinyCC 0.9.27 win32 工具目录：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-from-source.ps1 -CompilerPath 'C:\tools\tcc\tcc.exe'
```

入口准备固定版本且校验哈希的上游依赖，构建本项目原生模块，执行原生自测并验收发行包。输出为 `dist/DS-TH09-AI-v3.3.0-test.zip`，不会自动安装或启动游戏。完整依赖、离线构建和测试方法见 [BUILDING.md](BUILDING.md)。

玩家使用方法见 [package/README.md](package/README.md)。完整发行包可放在 GitHub Releases；`dist/`、`vendor/`、`downloads/`、`work/` 是本地生成目录，不作为源码提交。
