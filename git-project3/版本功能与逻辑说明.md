# 第三代：功能与逻辑说明（3.3.0-test）

**一句话介绍：少弹或收益不足时倾向养资源，弹幕密集时更积极用 C2 接连爆、维持能量；开放视野、注意力和变向参数供玩家配置难度。具备有限的毒减速应对能力，魔理沙激光及重叠激光仍有受击风险。当前未实现“超过 50W 后按压力选择断分”。**

## 主要行为

- **少弹养资源，多弹加快 C2 循环。** 在资源不足或未来形状更好时，会保留资源、调整位置或短暂等待；达到开花模式条件后，缩短 C2 的目标间隔。具体还要看连爆资源、真实能量、蓄力和动作门，并非仅由一个子弹数量决定。
- **保留普通射击和 C1。** C2 是主要循环手段，C1 仍用于合适的起爆与能量条件；本版没有主动选择 C3／C4 的策略，也不使用 X。不能把“多弹放 C”介绍成“多弹自动放 C3/C4”。
- **将压力反馈给放 C 节奏。** 当避弹受变向上限限制，或注意力持续过载时，策略会尝试更积极地安排已有的 C1／C2 行动。能量不足、无法蓄力或没有可达路线时仍可能受击，不会凭空补能量或获得保护。
- **参考对手气槽。** 有效读取到自己的气槽明显领先时，可以放宽开花模式的进入条件；这项读取本身不会直接触发攻击。

## 50W 规则：当前实际没有压力断分

“达到 50W 后，低压继续循环、高压选择断分”的规则属于此前讨论过的方向，**当前公开的 3.3.0-test 没有实现该断分状态机**。

当前不会因为 Spell Point 达到 500000 就进入断分，也没有与之对应的进入／恢复滞回、等待归零确认或断分等待超限逻辑。已有回归明确检查 499999、500000、900000 等分数不会触发旧停枪锁。

因此，这一版准确的介绍是“根据资源与压力调整放 C 节奏”。观察到短暂停 Z，可能是养资源、等待形状、释放蓄力或动作门限制，不能据此认定为按 50W 主动断分。分数仍可作为日志数据记录。

## 玩家可自定义的四项能力

| 参数 | 默认值 | 范围 | 作用 |
| --- | --- | --- | --- |
| 每秒避弹变向上限 | 6 | 1～10，整数 | 限制危险下的方向切换，持续同向移动不重复计数 |
| 自机圆形视野半径 | 448/3，约 149.33 | 16～640 | 避弹与放 C 的目标、资源及压力判断共用圈内信息 |
| 注意力容量 | human200 为 26 | 1～256 | 同时跟踪计费威胁的成本预算 |
| 每秒新目标额度 | human200 为 19 | 0.1～256 | 新目标纳入额度的补充速度 |

注意力是速度、形状加权的成本，不等于子弹颗数；其他预设有各自的预算，mech 默认关闭注意力限制。难度名称不保证固定存活时长。视野随自机移动，不降低角色移动速度，也不禁止连续横穿场地。

完整发行包内双击 `set-difficulty.cmd` 设置。详细预设和拉满效果见 [参数套装说明](docs/PARAMETER-PRESETS.md)。

## 毒与激光的实际能力

会结合毒造成的减速预测移动，因此对部分毒场有应对能力；**没有毒免疫或额外抗性**。本版还受圆形视野约束，毒、激光等免注意力预算的对象也不能绕过这个可见范围。

已有激光位置修正、跟踪与短期预测。玩家反馈的魔理沙激光及多条激光交叠场景仍应列为实战限制：可能判断不稳，也可能因移动预算、注意力、退路或能量受限而受击。不能把所有这类受击简单归结为完全看不见激光，也不能宣称已稳定解决。

## 代码依据

- `src/ai/bloom.lua`：开花模式、对手气槽、压力反馈与 C1／C2 选择。
- `src/ai/config.lua`、`src/ai/main.lua`、`src/ai/dodge.lua`：能力预设、用户参数与圆形视野。
- `tests/mock_ai_test.lua`：Spell Point 不影响新策略的回归用例。
- `src/native/README.md`：毒与激光感知的能力和边界。
