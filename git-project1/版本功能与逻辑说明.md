# 第一代：功能与逻辑说明（0.1.9）

**一句话介绍：偏被动的“懒人型”AI，以局部避弹为主，随机选择 C1～C4；Spell Point 达到 50 万后停 Z 尝试断分，归零后恢复。具备有限的毒减速应对能力，魔理沙激光及重叠激光仍有受击风险。**

## 主要行为

- **走位偏被动。** 主要根据当前位置附近的危险选择短期避弹路线，不主动经营大连爆或规划连续回能。“懒”是玩法风格描述，遇到危险时仍会移动避弹。
- **随机放 C。** 默认 C1、C2、C3、C4 的抽取权重各为 25。选定等级后等待对应能量；能量不足时仍进行普通点射，不因危险自动改抽或降级救命。它不是按弹幕多少选择 C 等级。
- **达到 50W 后尝试断分。** 检查的是当前 Spell Point，条件为 `>= 500000`，恰好 500000 也会进入。进入后停止继续按 Z，仍然避弹；必须等分数归零才恢复，掉回 49 万不会解除锁定。停 Z 不会直接修改或清零分数，已有连爆仍可能续分。
- **不使用 X 瞬发。** 移动与射击分别决定；支持的 Slow 操作模式中，Z 用于射击／蓄力，Shift 用于低速。

## 毒与激光的实际能力

“有一定抗毒性”更准确的意思是：**会读取毒造成的减速，并用减速后的移动能力预测路线**。没有给 AI 增加毒抗性数值或免疫；毒叠加、移速过低、退路被堵时仍可能受击。

当前代码已有激光位置修正、连续帧跟踪及短期轨迹预测。因此，“魔理沙激光看不清”适合作为玩家对实战表现的描述，不能理解成代码完全不读取激光，也不是屏幕图像识别功能。

根据玩家反馈，**魔理沙激光、多条激光交叉或重合时仍可能判断不稳、选错路线或被封路而撞上**。这里保留为实战限制，不把所有受击都归因于同一种感知错误，也不承诺已经解决重叠激光。

## 适用范围与代码依据

用于日文版 TH09 v1.50a 的本地 2P AI，2P Charge Type 需为 Slow。局部规划不保证长期无伤；本版没有后续版本的圆形视野、注意力和每秒变向参数菜单。

- `src/ai/main.lua`：`chooseChargeLevel`、`updateSpellLock`、`shouldPressZ`。
- `src/ai/config.lua`：50 万进入、0 分恢复、四档随机权重。
- `src/ai/dodge.lua`、`src/native/README.md`：毒减速、激光感知和有限预测。
