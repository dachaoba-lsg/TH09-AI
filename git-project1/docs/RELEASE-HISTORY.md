## 这次应发布什么

本轮提供 `TH09-AI-v0.1.9.zip` 首轮毒雾测试包，先由玩家使用梅蒂欣进行深度测试。它同时包含玩家运行包、中文 README、本项目源码、构建说明和第三方许可材料；不用让普通玩家再下载开发工具。本次打包不自动覆盖已经安装的游戏目录。

0.1.9 新增只读的中毒有效移动速度、临时保护及回充相关状态感知。Lua 将梅蒂欣毒雾作为非致死减速地形，用实际速度预测路线，并考虑临时保护结束后的危险。本功能不改变游戏原本的毒、保护或回充状态，不给2P加血或无敌。

本版不新增玩家配置项。能量足够时可以预持Z等待回充允许蓄力，但不把残留满蓄力误当新攻击；50万停Z和随机目标规则不变。状态快照缺失、无效或接口不匹配时停止全部AI输入并在控制台报错，不回退到忽略毒雾的旧策略。保护计时采用保守边界，提前一次更新恢复危险判断；尚无专门的低帧率或时停策略。

运行前须确认游戏Option中2P的`Charge Type = Slow`（长按Z蓄力、Shift低速）；相反的Charge模式不支持，检测到时AI停键并提示切回Slow，不自动更改1P设置。它不是JSON里的参数。

继续保留0.1.8的激光感知修正与动态短期预测：校正导给AI的起点偏移，按连续帧几何变化预测移动、伸缩和旋转。普通弹仍走快速连续路径，魔理沙EX不可碰撞的白光发射源不作为实心弹，零厚度激光仍为软预警。

随机 C1～C4、能量不足点射、50 万停 Z、从不按 X、默认 600 秒时限、按键隔离、练习开关和窗口功能不变。修复不改变游戏激光的真实物理、判定或 HP，也不改磁盘上的原版 `inject.dll`。

**必须使用完整新包，只替换 `dodge.lua` 不够。** 保留旧 `TH09-AI-v0.1.8.zip` 作为独立回退副本。本版已通过原生感知自测、真实x86桥接／输入／练习补丁回归、挂起启动和配置计时检查；挂起检查未创建游戏窗口或发送游戏输入。本轮尚无0.1.9毒雾功能的实战验收，不要宣传为“每次攻击必躲／永不被击中”。固定随机C规则不变，自适应主动C和高层能量规划仍未实现。如测试异常，请保存录像、`ai/ai_debug.csv`与`runtime/native-window.log`。

**不要把整个本地游戏目录或工程工作目录重新压缩上传。** 当前公开包不含原游戏、游戏解包素材、个人成绩与配置备份、测试录像或参考作者的视频。本项目公开的是 AI/辅助工具源码，不是《东方花映塚》的原始游戏源码，也没有需要发布的“采集数据集”。
