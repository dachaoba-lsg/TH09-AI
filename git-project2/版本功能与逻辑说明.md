# 第二代：功能与逻辑说明（2.0.7）

**一句话介绍：主动经营妖精、灵和白弹构成的大连爆，以 C2 循环为主要进攻与生存手段，配合普通射击和 C1 起爆。具备有限的毒减速应对能力，魔理沙激光及重叠激光仍有受击风险。**

## 主要行为

- **主动追求连爆收益。** 观察妖精、灵与白弹的位置关系，评估起爆点和连通链，选择靠近、对齐、短暂低速固灵或等待更有利的形状。养资源和等待都有边界，不会无限等待理想连爆。
- **以 C2 为主，但并非只释放 C2。** 当前策略也会使用普通射击和 C1；当 C1 更适合起爆、预计收益更好或能量不足以放 C2 时，都可能选择 C1。主动蓄力目标为 C1／C2，不主动选择 C3／C4，也不使用 X。
- **有独立的 C2 节奏。** 不让普攻或 C1 无限拖延下一次 C2；资源形状丰富时会加快循环。C2 实际生效后，再结合真实保护、下半场资源和压力调整接链位置。
- **区分消弹与回能。** 策略不会把 C2 直接吞掉白弹一概当作返弹或能量收益；重点考虑妖精／灵引起的连爆。预测存在误差，不能保证每发 C2 都回本或越放能量越多。
- **没有第一代的 50W 停枪锁。** Spell Point 达到或超过 50 万，不会仅因这个分数进入停 Z 等待归零。为了养资源、等待形状或动作门而短暂停 Z，也不等于实现了按分数断分。

## 2.0.7 的灵梦 C1 修复

主动 C1 会核对敌人实际血量、固灵状态、受伤门和符札伤害，逐次处理前方目标挡掉非穿透符，并按预计命中时间计算原链收益。无法证明击破时，不再借用普通枪评分强行选择 C1；原固灵／普通射击流程继续经营。请求 Shift 不等于灵已激活。蓄力中失去依据可在未蓄成时取消，期限与已蓄成后的物理释放仍保留。

详见 [2.0.7 灵梦 C1 修复](docs/REIMU-C1-2.0.7.md)。模型有范围和性能限制，不保证每发 C1 成功或全场景 60 FPS。

## 毒与激光的实际能力

会读取毒造成的减速，并按实际可移动速度规划路线，可以应对部分毒场；**没有额外毒抗性或毒免疫**。多层毒导致移动过慢、连爆位置受阻或退路封死时，仍可能受击。

已有激光位置修正、连续帧跟踪和短期轨迹预测。按照玩家反馈，魔理沙激光、多条激光交叉或重合时仍可能处理不稳并撞上。对外可写“激光处理仍有局限”，不宜写成完全没有激光感知；具体受击也可能与可达路线不足有关。

## 与第一代的区别

第一代主要避弹并随机等待某个 C 等级；本版会主动选择起爆方式、固灵和连爆位置，以经营资源推动 C2 循环。它也取消了第一代固定的 50W 停枪规则，但尚未提供第三代的四项玩家能力设置。
