# TH09-AI 2.0.8

简明功能与逻辑见 [版本说明](版本功能与逻辑说明.md)。

《东方花映塚》日文版 v1.50a 的本地 2P AI 源码。Lua 负责决策，本项目的原生启动器和支持模块提供输入隔离、窗口处理及只读感知，运行时使用上游 ka_ai_duka v1.7。

这是第二代开花测试版本，以 C1/C2、短时固灵、连爆资源和 C2 循环经营为核心，保留毒与激光避弹。需要自行准备游戏；仓库不包含游戏本体。

## 2.0.8：开花机兼容毒优化

当前已经处于实际生效的毒云中时，在原开花选出的**同一 Shift 状态**内，优先选择毒层更少的安全移动方向。候选仍使用原来的真实毒减速和墙限制轨迹，依次比较短路径平均毒层数、终点层数；层数相同时，再以靠近最近一层有效毒云边界作为短程引导。单朵毒云内的减速并不随距离连续变淡。

原弹幕碰撞、墙、高度、保护到期落点和同一份软风险预算继续约束选择；不会为了少毒去撞弹、额外放宽一次风险，或擅自增加/取消 Shift。仅当前实际中毒、有效感知、正常时间倍率且允许移动时启用；无毒或门条件不满足时保持原选路。深度叠毒或长期围堵仍可能没有可达出口。

固灵、普通射击、灵梦 C1、C2 节奏、连爆经营与原生源码保持 2.0.7；移动改变可能间接影响之后的资源对齐和收益。这是第二代原路线上的方向偏好，没有引入第三代的移动习惯、视野/注意力参数或毒导航模块。默认在 `ai/config.lua` 的 `dodge.poison_escape_enabled=true` 开启，设为 false 可对照原选路；启动器 JSON 不新增设置。

CSV 保留原 113 列，追加 5 列毒偏好诊断，共 118 列。开发交付记录为 23 套 Lua、原包及随包源码重建各 246 项包检查通过；这是此前开发验证证据，本次公开源码同步不冒称重新完成全部测试，也不代表用户已实战验收。详细说明见 [低毒移动](docs/POISON-MOVEMENT-2.0.8.md)。

## 行为与边界

- 在 Match Mode → Human vs Human 中控制 2P。2P 的 `Charge Type` 必须为 `Slow`；AI 不使用 X。
- 根据妖精、灵和白弹连爆资源选择普通射击、C1/C2；不再随机选择 C，也没有第一代的 500000 分停枪规则。
- 使用短时低速固灵和有界接近。策略活动高度为 Y ≥ 150，真实场地与角色物理边界不变。
- C2 具有独立节奏，资源充足时可缩短循环；C1 不推迟 C2 的期限。能量不足、动作门或受击仍可能延后释放。
- 区分 C2 直接吞弹与连爆可能产生的回能；请求释放、几何覆盖、预计连爆和真实回能不是同一件事。
- `launcher-settings.json` 顶层 `seconds` 默认 600；0 表示关闭接管时限。时限不等于存活保证。

部分角色的 C1 自定义回调、未来攻击运动及消弹圈与爆风竞速仍使用有限模型。现有保护来自读取到的真实状态，不能把计划中的下一次 C2 当作无敌。此版本没有第三代的四项玩家能力参数，也不承诺纯开花或固定存活时间。

原生感知修正作用于 AI 读取的数据，不修改游戏的子弹生成、碰撞物理、2P HP 或能量。离线测试不能代替实战验证。

## 2.0.7 灵梦 C1 修复

灵梦 C1 现在结合目标实际 HP、受伤门、固灵状态和符札消耗判断能否击破；按已核实的展开／追踪运动与实际蓄力延迟估计原链收益。证据不足时保留固灵或普通射击经营，不再把几何接触当成必然起爆。蓄力途中也会重新检查依据。期限或已蓄成后的物理释放仍可能产生无理想目标的 C1，不保证每发成功。

2.0.6 的 C2 节奏、避弹及输入映射继续保留。完整说明见 [灵梦 C1 修复](docs/REIMU-C1-2.0.7.md)，Lua 与原生 DLL 必须整包配套。

## 从源码构建

在仓库根目录运行，示例编译器路径请替换为自己的完整 TinyCC 0.9.27 win32 工具目录：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-from-source.ps1 -CompilerPath 'C:\tools\tcc\tcc.exe'
```

入口准备固定版本且校验哈希的上游依赖，构建本项目原生模块，执行原生自测并验收发行包。输出为 `dist/TH09-AI-v2.0.8.zip`，不会自动安装或启动游戏。完整依赖、离线构建和测试方法见 [BUILDING.md](BUILDING.md)。

玩家使用方法见 [package/README.md](package/README.md)。完整发行包可放在 GitHub Releases；`dist/`、`vendor/`、`downloads/`、`work/` 是本地生成目录，不作为源码提交。
